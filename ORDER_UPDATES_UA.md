# Оновлення замовлень DEMI DEVILLE — 09.10.2026

1. В адмінці **Заказы** є **Удалить заказ**. Він прибирає замовлення з активного списку й переміщує до архіву. Відновлення — увімкнути «Показать удалённые (архив)» → «Восстановить». Архівування не повертає кошти Stripe і не видаляє платіжну історію.
2. **Доставка для новых заказов** змінює стандартну ціну доставки для всіх НОВИХ покупок на Checkout. Можна задати 0.
3. **Стоимость доставки** всередині картки замовлення — облікова вартість логістики для конкретного замовлення. Її можна змінити незалежно від статусу оплати, але вона НЕ змінює вже погоджену суму Stripe чи загальний підсумок покупки.
4. Унизу адмінського списку замовлень і Checkout доданий невеликий запас для прокручування (~80–100 px).
5. Записи замовлень і облікова доставка зберігаються в поточній PostgreSQL за умови налаштованого DATABASE_URL.
